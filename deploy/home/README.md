# تشغيل سايح من جهازك في البيت

دليل تشغيل المتجر على جهاز عندك بدل سيرفر مؤجّر. مجاني بالكامل، وما يحتاج بطاقة ولا IP ثابت ولا فتح بورتات في الراوتر.

الفكرة: جهازك يشغّل نفس البرامج اللي تشتغل على السيرفر، و**Tailscale Funnel** يعطيك رابط HTTPS علني ثابت يوصّل الزبائن لجهازك من غير ما يكون عندك عنوان علني.

---

## قبل ما تبدأ

**تحتاج:**
- جهاز يقدر يقعد شغّال 24 ساعة — لابتوب قديم يمشي الحال. 2 جيجا رام كافية، 4 مريحة.
- إنترنت في البيت (أي نوع، حتى خلف CGNAT).
- تلفون أندرويد فيه شريحة **ليبيانا** لتحويل الرسائل. هذا مطلوب في كل الأحوال — حتى لو استأجرت سيرفر — لأنه هو اللي يستقبل رسالة التحويل ويبعتها للمتجر.
- حساب مجاني على [tailscale.com](https://tailscale.com) — تسجّل بجوجل أو جيتهب، بدون بطاقة.

**ما تحتاج:** دومين، ولا بطاقة، ولا IP ثابت، ولا تعديل في الراوتر.

---

## الخطوة صفر: جهّز أوبنتو

### لو الجهاز عليه ويندوز

شغّل PowerShell **كمسؤول** ونفّذ:

```powershell
wsl --install -d Ubuntu
```

بعد إعادة التشغيل، افتح Ubuntu من قائمة ابدأ وسوي اسم مستخدم وكلمة سر. بعدها فعّل systemd — بدونه ما في شيء يشتغل تلقائياً عند الإقلاع:

```bash
printf '[boot]\nsystemd=true\n' | sudo tee -a /etc/wsl.conf
```

ورجّع لـ PowerShell:

```powershell
wsl --shutdown
```

ثم افتح Ubuntu من جديد.

> ⚠️ **مهم في ويندوز:** لازم تعطّل السكون (Sleep) من إعدادات ويندوز نفسه: `Settings ← System ← Power` وخلّي كل شيء على **Never**. سكربت الإعداد يعطّل سكون لينكس بس، وويندوز فوقه يقدر ينوّم الجهاز كله ويوقف المتجر.

### لو الجهاز عليه لينكس

تأكد إنه أوبنتو 22.04 أو 24.04، وامش للخطوة الجاية مباشرة.

## الخطوة ١: شغّل سكربت الإعداد

```bash
sudo apt-get update && sudo apt-get install -y git
git clone https://github.com/<owner>/App.git ~/sayeh-src
cd ~/sayeh-src

sudo REPO_URL=https://github.com/<owner>/App.git \
     DB_PASSWORD='حط-كلمة-سر-قوية-هنا' \
     ./deploy/home/setup-home.sh
```

في نص التشغيل بيطلع لك رابط — افتحه في المتصفح وسجّل دخول لتفعيل الجهاز على Tailscale. بعدها السكربت يكمّل لحاله ويطبع لك العنوان العلني، شكله:

```
https://sayeh.tailXXXX.ts.net
```

**هذا هو عنوان متجرك. احفظه.**

السكربت يركّب ويضبط: Node، PostgreSQL، Nginx، Tailscale، خدمة الـ API، النسخ الاحتياطي الليلي، ويعطّل سكون الجهاز.

## الخطوة ٢: املأ الإعدادات

```bash
sudo nano /opt/store/app/backend/.env
```

المطلوب قبل ما يشتغل:

| المتغيّر | شنو |
|---|---|
| `SMS_GATEWAY_URL` | بوابة إرسال رموز التحقق |
| `SUPPORT_WHATSAPP` | رقم الدعم اللي يشوفه الزبون |
| `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` | حساب الأدمن |
| `LIBYA_PLAY_API_KEY` / `LIBYA_PLAY_EMAIL` | مورّد البطاقات |
| `PLUS_API_KEY` | مورّد خدمات المتابعين |
| `PLUS_USD_TO_LYD_RATE` | سعر صرف الدولار للدينار |

التطبيق **يرفض يشتغل** بدون المطلوب منها — وهذا مقصود: لو اشتغل بدون بوابة الرسائل، رموز التحقق راح تنطبع في السجل بدل ما توصل الزبون.

افتح `https://sayeh.tailXXXX.ts.net` في المتصفح — لازم تشوف لوحة الأدمن.

## التحقق من عدد الوسطاء (خطوة أمنية مهمة)

عندك **وسيطين** بين الزبون والـ API: Tailscale ثم Nginx. الملف `.env` يضبط `TRUST_PROXY_HOPS=2` عشان يحسبهم صح.

ليش يهم؟ لأن حدود الطلبات (rate limit) تُحسب حسب عنوان الزبون. لو الرقم غلط، السيرفر يشوف كل الزبائن بعنوان واحد ويحطهم في سلة وحدة — زبون واحد يكثّر الطلبات فيتقفل المتجر على الجميع. والأسوأ: **ما في أي رسالة خطأ تدلّك**، كل شيء يبان طبيعي.

هذا مقاس فعلياً على نفس الإعداد:

| الإعداد | زبون أ (أول طلب) | زبون ب (أول طلب) | النتيجة |
|---|---|---|---|
| `TRUST_PROXY_HOPS=2` | 4 متبقية | **4 متبقية** | ✅ كل زبون له سلته |
| `TRUST_PROXY_HOPS=1` | 4 متبقية | **3 متبقية** | ❌ الاثنان في سلة واحدة |

**تأكد بنفسك** — افتح المتجر من تلفونك **على بيانات الجوال** (مش الواي فاي)، وبعدها على الجهاز:

```bash
sudo tail -5 /var/log/nginx/sayeh-access.log
```

لازم تشوف عنوان تلفونك الحقيقي في `fwd="..."`:

```
127.0.0.1 fwd="41.208.x.x" "GET /api/v1/catalog/categories HTTP/1.1" 200
```

- **عنوان واحد في `fwd`** ← `TRUST_PROXY_HOPS=2` صحيح، ما تغيّر شيء.
- **عنوانين أو أكثر** ← زد الرقم بنفس المقدار في `.env` ثم `sudo systemctl restart store-backend`.
- **`fwd` فاضي أو `127.0.0.1`** ← Tailscale ما يمرّر عنوان الزبون؛ ارجع لـ `TRUST_PROXY_HOPS=1`، وخلي حدود الطلبات على الحساب (اللي تشتغل أصلاً) هي خط الدفاع.

## التشغيل اليومي

```bash
# هل كل شيء شغّال؟
sudo systemctl status store-backend nginx postgresql

# سجل الأخطاء
sudo journalctl -u store-backend -f

# رابط المتجر العلني
tailscale status

# تحديث لآخر نسخة من الكود
sudo /opt/store/app/deploy/deploy.sh
```

**النسخ الاحتياطي** يمشي كل ليلة تلقائياً إلى `/opt/store/backups`. بس هذا على نفس الجهاز — لو خرب القرص راح كل شيء معه. **انسخها لمكان ثاني** (فلاشة أو جوجل درايف) كل أسبوع على الأقل:

```bash
ls -lh /opt/store/backups
```

وللتأكد إن النسخة سليمة فعلاً — مش مجرد ملف موجود:

```bash
sudo /opt/store/app/deploy/restore.sh /opt/store/backups/<اسم-الملف>.dump
```

يسترجع على قاعدة تجريبية منفصلة ويطبع عدد الصفوف، وما يمسّ بيانات المتجر إطلاقاً. (تشغيله بدون اسم ملف يعرض لك قائمة النسخ المتاحة.)

## شنو ينقص مقارنة بسيرفر مؤجّر؟

كن صريح مع نفسك في هذي النقاط:

| | البيت | سيرفر مؤجّر |
|---|---|---|
| الكهرباء | انقطعت = المتجر واقف | مضمونة |
| الإنترنت | انقطع = المتجر واقف | مضمون |
| التكلفة | صفر | من 5 دولار/شهر |
| النسخ الاحتياطي | على نفس القرص، تنسخه بيدك | تقدر ترفعه لتخزين خارجي |

**الحل العملي للكهرباء:** لابتوب أفضل من كمبيوتر مكتبي — بطاريته UPS جاهز يمشي ساعات. تأكد بس إن البطارية لسه تشحن.

**متى تنقل لسيرفر مؤجّر؟** لما تبدأ تخسر طلبات بسبب انقطاع، أو يصير عندك دخل يغطي 5 دولار في الشهر. النقل سهل:

```bash
# على الجهاز القديم
sudo /opt/store/app/deploy/backup.sh

# انسخ آخر ملف من /opt/store/backups للسيرفر الجديد، وبعد provision.sh هناك:
sudo /opt/store/app/deploy/restore.sh --live /path/to/backup.dump
```

وبعدها تبني نسخة APK جديدة على العنوان الجديد. ما تخسر ولا طلب ولا دينار من محافظ الزبائن.

## أسئلة متكررة

**الجهاز انطفأ، شن يصير؟** كل الخدمات تشتغل تلقائياً عند الإقلاع. بس Tailscale لازم يرجع يتصل — عادة تلقائي، تأكد بـ `tailscale status`.

**أقدر أستعمل الجهاز عادي وهو شغّال؟** نعم، المتجر ياخذ موارد قليلة. بس **لا تطفيه ولا تنوّمه**.

**الرابط `.ts.net` يتغير؟** لا، يظل ثابت طول ما الجهاز مربوط بنفس حساب Tailscale وبنفس الاسم.

**أقدر أربطه بدومين حقي بعدين؟** نعم — تشتري دومين وتحطه على Cloudflare وتشغّل Cloudflare Tunnel بدل Funnel. التطبيق يحتاج نسخة جديدة وقتها، فالأفضل تقرر الاسم قبل ما توزّع APK على زبائن كثار.
